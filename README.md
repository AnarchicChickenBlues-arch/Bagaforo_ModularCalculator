# Bagaforo_ModularCalculator
Modulate Calculator by Jeff Bagaforo


Reflection

1. What functions did you create in your calculator program?
  
  In my program, I created 4 functions to assist my calculator. Those functions being add, subtract, multiply, and divide.
  
2. What parameters did your functions use?
 
  My functions used the parameters "value1" and "value2".
  
3. What arguments were passed when the functions were called?
  
  The arguments that were passed when the function called in the "if/elif" blocks was the variables "value1" and "value2" that contained the float numbers that I inputted in the code.
  
4. How did your program use the returned value?
 
  The value was used in the result variable that was later displayed using the f-string to show the final statement.
  
5. Why is it better to divide the calculator program into functions instead of writing everything in one long block of code?

  To separate all the math-logic code from user-input code and using the created functions to reuse instead of rewriting the addition logic. It also isolates the codes from breaking during the debugging process.
